# 竞潮小学信息科技课堂 · v9.2

**竞潮小学 · 章沂婷老师作品**

已部署到 http://120.26.210.129 ，默认示例为小学六年级信息科技。

## 开始使用

1. 使用交付的教师账号登录。在“系统设置”中修改初始密码。
2. 在“班级管理”中创建自己的班级，将网站地址和邀请码交给学生。学生在登录页选择“使用邀请码加入”，也可由教师创建学生账号。
3. 在“智能备课”中编辑示例或新建教案，手动编写或配置模型后使用 AI 起草。内容经审核可分享给所选班级。
4. 在“作业中心”配置单选、多选、判断、填空、简答的题数与每题分值，补充难度、目标和易错点。AI 每次最多生成 30 题，先预览再追加或替换。手动编辑或导入最多 50 题。
5. 外部题目支持 CSV、JSON、按模板整理的 TXT/Markdown/DOCX（2 MB 内）。下载模板、上传文件或粘贴文本，检查题目与答案后采用。格式零散的文本可由 AI 辅助整理，缺少答案时不会静默补齐。
6. 学生作答在当前浏览器标签页暂存，提交后保存到服务器。单选、多选、判断按答案判对错；多选全选对才得分。填空每题一个空，支持可接受答案与大小写规则。简答可手动批改或请求 AI 建议。
7. 在“批改工作台”逐份处理或选择多份连续生成建议。AI 建议独立保存，不会直接发布成绩。教师核对得分、依据、错因和下一步，确认后学生才能看到结果。已有提交的作业题目会锁定，需复制后修改。
8. “学情分析”先选班级，再选一份作业。逐题显示满分、部分得分、零分人数、正确率、选项分布与学生作答矩阵；未交和待批单独列出，不计为错误。支持逐题统计和本次成绩 CSV 导出。
9. “AI 教学建议”只分析本次作业的匿名统计，区分事实与可能解释，给出优先讲解题目、10–15 分钟补救活动和跟进检查题。可保存为可编辑教学反思，或据此设计补救练习。
10. 教案、资源、教学设计、反思与微课均提供结构化条件、新稿预览、原文修订、采用与撤销。学习伙伴提供算法、数据与信息核验模板；海报可先生成文案再排版。
11. 学生可在“学习回顾”按作业查看反馈、参考答案与解析，记录自己的新理解。首页小实验可拖动时间，观察条件判断的分支。
12. 在“成果中心”导出作品 ZIP；海报、处理后的图片、字幕和旁白文稿在多媒体工坊单独下载。

## v9.2：带着成长伙伴去探索

- 在成长伙伴中领养后，进入草原、长安、古埃及或恐龙世界会自动读取当前学生自己的品种、昵称与成长阶段，出现对应的立体小龙、小兔、小狗或小猫。
- 宠物沿着学生走过的路线跟随，停步会转头看向学生；跑步、跳跃与飞行都有动作。小龙展开翅膀，其他伙伴使用小光翼。地图传送和回到入口会一同到达，遇到狭窄障碍无法跟上时会以短暂聚光回到安全位置。
- 仅获取已有宠物，不自动领养、改名、喂食或发放成长奖励。没有宠物时提供领养入口，教师体验场景不读取学生的私人宠物。
- 手机横屏、减少动态偏好和场景退出资源清理均支持。介绍页新增结伴飞行实拍，七幕场景展示按真实图片比例和底部导航高度适配，修复说明与导航重叠。

## v9.1：从一份备课包，到四个探索世界

- **主题备课包 `/#lessonkit`**：教师输入主题、年级、课时、目标与题型题量，依次生成教案、PPT 和配套作业。每个阶段独立保存，失败可续接，成果默认是草稿。PPT 可逐页修改标题、要点与教师备注，下载真正可编辑的 16:9 `.pptx`。当前版式使用原生文字和几何图形，不自动生成原生图表、照片或动画。“先看看完整示例”明确为内置人工示例，无需模型。
- **时空之门 `/#portals`**：盛唐长安、古埃及金字塔、恐龙时代三个原创三维学习场景，每个四处知识站。可以行走、跑步、转视角、连跳飞行、地图传送、高清留影；建筑和地景有碰撞。导览员提供内置讲解、问答、小挑战与来源链接，配置模型后支持主题 AI 问答。答题进度按账号保存在服务器，不计正式成绩。长安和埃及是艺术化学习模型；恐龙是跨时期虚拟展区，不声称不同动物真实同时共存。
- **成长伙伴 `/#pets`**：学生选择小龙、小兔、小狗或小猫，命名、喂食、换造型，成长保留。庭院支持小跑、跳跃、睡觉打呼噜和叫醒；腿、耳朵、翅膀和尾巴随动作变化。默认无声音，尊重减少动态偏好；离开页面或切到后台会停止动作，玩耍不额外奖励经验。完成真实作业、获得教师确认的高质量反馈、通过操作练习或点亮探索知识站可领取一次性成长和口粮；重复同步不会重复奖励。教师只能鼓励自己班级的学生，需要填写具体表现，奖励受每日上限约束。饱腹随时间缓慢下降，最低保留健康休息状态；不死亡、不掉经验、不影响正式成绩，每日有免费口粮。
- **全站液态玻璃控件**：输入框、填空、选择项、单选复选和容器统一透光；聚焦时蓝、紫、粉、金、薄荷色沿边缘流动，文字保持稳定。保留键盘操作与原生校验，尊重减少动态、高对比度及减少透明度偏好。
- **介绍页**：“从一个想法，到下一堂更好的课”逐幕展示备课、教案、课件、作业、批改、学情和反馈；原野展示扩展到三座时空场景，并增加四种成长伙伴的跑跳/睡觉动作演示与实际界面。均使用本地示例账号的真实界面或场景留影，可放大、按章节跳转与顺序阅读。原“让工具围绕课堂，让课堂围绕学生”理念区保留。分数演示改为蓝色先下、黄色再下、最后合并，不复制颜色块。

三维画面和宠物动画在学生浏览器执行，服务器提供登录、课程、进度与奖励数据。低性能设备可切换流畅模式；无法显示 WebGL 时仍可从知识地图学习。手机横屏显示摇杆和跳跃键，竖屏提供方向提示和地图入口。

AI 生成和自由问答依赖教师配置的模型。内置示例与固定测试响应不代表真实模型实测。历史事实、教学正确性和生成内容仍由教师审核；来源链接供进一步核验。

## v9.0：真正可操作的进阶课堂

入口：`/#practice`。师生可使用三节内置进阶课，原有三节基础课继续保留：

- **Word · 校园观察报告**：选择图片、更改嵌入型/四周型/上下型环绕，拖动到左右位置并真实重排文字；段落对话框设置行距和段后间距。检查完整正文、四周型、左侧位置、1.5 倍行距、段后 8 磅。
- **Excel · 校园回收记录**：编辑单元格和公式栏，名称框选择区域，SUM 求和、相对引用向下填充、百分比/数值显示、两列数据柱形图及数据标签。修改原数据后，公式与图表即时重新计算。检查 SUM 范围、每行公式与完成率、显示格式、图表引用与标题；只填上计算答案不能通过公式目标。
- **PPT · 校园观察计划**：创建文本框和艺术字、输入文字、切换渐变样式和阴影，拖动对象及手柄改变位置/尺寸，Ctrl/⌘ 或列表勾选多选后左对齐。检查对象类型、内容、样式、对齐、宽度及避免重叠/出界的版面条件。

“自己练”与“逐步演示”使用不同作品模型。看演示、回看某一步不会覆盖学生的作品。进阶课支持撤销/重做；“保存进度”保存到当前账号，下次可恢复；未保存修改另在当前标签页暂存。不同页面同时保存时通过版本校验防止静默覆盖。重置可用撤销找回，并不会立即覆盖服务器作品。

“检查练习”先保存，再由服务器根据作品内容与参数逐项判断，返回未完成项的具体修改提示。表格公式由白名单解析器重新计算，不使用 eval，也不信任浏览器提交的计算结果。教师在班级练习记录中查看尝试次数、曾完成状态、最近一次检查及修改提示；练习记录不计入正式作业成绩。

这里是可操作的独立办公教学仿真，不是 Microsoft Office，也不是远程控制学生电脑；不读写真实 DOCX/XLSX/PPTX。检查的是作品最终状态，不是鼠标点击轨迹。表格范围为 A1:L30，支持 SUM、AVERAGE、四则运算、单元格引用和填充时的绝对引用；没有宏、外链或任意脚本。进阶课程目前是经过验证的三节内置课；AI 操作课设计器仍面向基础 Word/PPT 步骤。

师生端、登录、助手说明、介绍页、下载材料及可见媒体统一为“竞潮小学 · 章沂婷老师作品”。介绍页新增真实进阶练习入口和能力说明，带旧品牌的界面截图已重拍，三段高清仿真视频已重新制作；旧媒体从公开资源中移除。服务器内部既有服务名、目录及历史存储键保持兼容，避免破坏原有数据和运行配置。

新文件：`office.py`、`office_lessons.json`、`static/office-model.mjs`、`static/office-classroom.mjs`、`static/office-classroom.css`。启动时仅新增 `practice_drafts` 表，复用已有练习记录；原班级、作业、成绩和模型设置不迁移、不重置。

验证覆盖三节课从操作到通过、故意错误的反馈、公式重新计算与循环/非法公式、保存恢复/版本冲突、师生数据隔离、教师明细，以及桌面与窄屏布局。真实付费模型没有参与本轮测试；这些课堂练习无需模型即可使用。

## 介绍页交互教学案例（页面 v7.1）

访问 `/intro/#web-creation`，无需登录或模型配置即可体验三个平台制作的示例：

- **分数怎么相加**：三组算式，先比较大小，再等分、相加；支持播放/暂停、单步、换题、重置，并验证通分前后的量不变。
- **让数字亮起来**：八位二进制灯，点击开关、拖动 0—255 滑块、单步或自动计数；专门展示 7→8 进位，并有预测题反馈。
- **图片与文字相遇**：用实际文字重排演示嵌入型/四周型、左右位置与图片大小；提供排版任务检查。这是 Word/WPS 概念仿真，不是真实 Office。

每个示例附可复制的完整创作指令，可到 `/#webstudio` 粘贴并生成自己的版本。支持大屏演示、键盘切换、手机布局和减少动态效果；切换示例、离开视野或后台时停止播放。交互仅在当前浏览器中运行，不保存答题记录、不产生模型费用。单文件《竞潮小学系统介绍页.html》已内嵌脚本、样式和图片，可离线演示这些案例。

本次只更新介绍页静态资源及说明，后端版本仍为 7.0.0。示例为平台预制内容，不冒充 AI 生成结果；生成作品仍需检查知识和演示是否正确。

## 网页创作与全站玻璃材质（v7.0）

学生和教师导航新增“网页创作”（`/#webstudio`）。输入指令或题目，选择动画讲解、小程序、网页，调用教师配置的 OpenAI 兼容模型生成完整单文件 HTML/CSS/JavaScript。可操作预览、大屏展示、停止/重新运行、追加修改、恢复最近 10 个版本、下载 HTML；模型返回不完整时保留旧作品并说明原因；浏览器运行报错可一键带回修改指令。

- 每个账号最多 12 个作品；临时链接默认 7 天，可续期、停用，重新启用时更换随机地址。过期链接返回 410，作者仍可预览、下载和续期。作品只允许作者管理；持有链接可查看作品，不公开作者身份和指令。

## 探索草原（v6.0）

访问 `/#explore`，或点击学生首页的“进入探索草原”。教师也可从导航进入体验。

## 模型配置

“系统设置”中填写服务商提供的 Base URL、准确模型 ID 和 API 密钥，保存后点击测试。支持 OpenAI 兼容的 `/chat/completions` 接口。Base URL 通常以 `/v1` 结尾，不重复填写 `/chat/completions`。

API 密钥在服务器端加密保存，不返回浏览器。对话和生成会向配置的服务商发送必要的输入；学情总结仅发送匿名汇总。尚未配置密钥时，AI 生成、对话、辅助评分和总结明确提示未配置，其他功能可正常使用。

当前按用户选择保留 HTTP。HTTP 本身不加密登录凭据或配置输入；可在可信网络使用，或通过 SSH 本地转发访问后台后再填写密钥。未来可以单独配置 HTTPS，当前未申请证书或设置证书续期。

## 数据与边界

- 初始班级、八名学生、教案、两份作业及成绩均为标注过的演示数据，没有导入真实学生信息。
- 新建真实班级后，可在学情分析中切换班级；教师可以创建多个班级，学生可加入多个班级。
- 当前提供一个初始教师管理账号，未开放公众教师自助注册。
- 学生端不会收到未发布作业、教师参考答案、评分标准、密钥或其他学生的记录。
- 教师确认成绩前，学生看不到未确认的自动评分与 AI 评分建议。已经确认的作业不能由学生重新覆盖。
- AI 分数是建议，需教师确认；模型实际输出质量和可用性需在用户配置有效接口后验证。
- 多媒体功能提供图片处理、排版海报、脚本和字幕；旁白为浏览器试听，当前没有把它伪装为音频或视频生成文件，也没有接入专门的文生图模型。
- 作业支持五种题型；填空每题一个空，多选全对才得分。不包括手写扫描 OCR、学生文件附件或复杂编程题自动评测。DOCX 需按题目文本模板整理。
- 导入成绩与平台作业分别展示，不自动合并或推断姓名对应关系。
- 教学作品 ZIP 不包含学生姓名、答案、聊天记录、数据库或 API 密钥。

服务器位置：

- 应用：`/opt/zhixu/app`
- 完整部署源码：`/opt/zhixu/source`
- Python 环境：`/opt/zhixu/venv`
- 数据库和加密材料：`/var/lib/zhixu`
- 服务：`zhixu.service`，已启用开机启动及异常重启
- 网关配置：`/etc/nginx/sites-available/zhixu`
- 首次备份：`/var/backups/zhixu/zhixu-20261028T034616Z`

常用维护命令：

```bash
systemctl status zhixu
journalctl -u zhixu -n 100 --no-pager
systemctl restart zhixu
/opt/zhixu/venv/bin/python /opt/zhixu/source/deploy/backup.py /var/backups/zhixu
```

备份必须同时保留数据库、`encryption.key` 与 `session.key`。恢复前停止服务，恢复后将数据目录所有者设为 zhixu、目录权限设为 700、文件权限设为 600，再启动服务。备份为手动触发，未设置定时备份。

本地启动：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

默认地址 http://127.0.0.1:8088 。首次启动生成随机账号，保存在 `data/initial-accounts.json`，不会写入源码。建议使用 `requirements.lock.txt` 重现本次服务器版本。

node --check static/app.js
node --check static/assessment.js
node --check static/creative.js
node --check static/workspace.js
